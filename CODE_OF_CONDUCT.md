# Code of conduct

## Our pledge

We want DAWN Core to be a place where anyone can learn about music software and build
agents, regardless of experience, identity or background.

## Expected behavior

- Be direct about code and kind about people.
- Assume good faith. Ask before assuming.
- Give reproductions, not just opinions.
- Respect that music taste is subjective; argue about the code, not the genre.

## Unacceptable behavior

- Harassment, insults, or discriminatory language.
- Publishing someone's private information.
- Sustained disruption of discussions or reviews.
- Sexualized content or attention in project spaces.

## Enforcement

Report issues to the maintainer via a private GitHub message. Reports are handled
confidentially. Consequences range from a warning to a permanent ban, at the maintainer's
discretion.

This is a short, project-specific code of conduct. It is not a legal document.
