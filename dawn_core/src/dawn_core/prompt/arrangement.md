# Arrangement doctrine

## Phrases and sections

- Work in 4/4 unless the user says otherwise. Build in 8- or 16-bar phrases.
- The common shapes: intro, verse, build, drop or chorus, breakdown, second drop, outro.
  Use only the sections the track needs.
- A section change should be audible within one bar: add or remove an element, change the
  filter, change the drum pattern, or change the bass.

## Energy

- Arrange by energy, not by instrument count. Each section should have a clear job.
- The drop is defined by what was withheld before it. Remove elements in the build rather
  than adding more.
- Leave one or two bars of space before a drop. Silence is an arrangement tool.
- Do not let every element play in every section.

## Session view first

- Build a loop in Session view: drums, bass, harmony, lead, texture. Get the groove right
  before arranging.
- Copy the loop to Arrangement view and edit the timeline there. Do not try to arrange by
  firing scenes forever.
- Name and colour tracks and scenes as you go. A clear Session is easier to arrange.

## Transitions

- Use risers, reverses, filter sweeps and short silences sparingly; one transition device
  per section change is usually enough.
- Automate the few parameters that carry the transition (filter cutoff, reverb send, volume)
  rather than many small moves.
- Check the transition at low volume and in mono.
